# Bundled English font

Source Serif 4 is used for editorial headings. This original variable WOFF2 file is served by this project, with no external font service at runtime. Body text, controls and identifiers use the system sans-serif stack: the system UI font on macOS, Segoe UI on Windows, then Helvetica Neue / Arial and Chinese system fallbacks.

Source: https://github.com/adobe-fonts/source-serif

The original SIL Open Font License 1.1 notice is included as `Source-serif-LICENSE.md`. The font file is unmodified. `sources.json` records its original blob identifier, download location, file size and SHA-256 value.
