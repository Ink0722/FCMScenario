# Bundled English fonts

Source Serif 4 is used for editorial headings. This original variable WOFF2 file is served by this project, with no external font service at runtime. Body text, controls and identifiers use the original system sans-serif stack: the system UI font on macOS, Segoe UI on Windows, then Helvetica Neue / Arial and Chinese system fallbacks.

Source Sans 3 remains here with its license and provenance for the previous version, but is no longer declared, preloaded or requested by the interface as of UI 0.5.1.

Sources:
- https://github.com/adobe-fonts/source-sans
- https://github.com/adobe-fonts/source-serif

Original SIL Open Font License 1.1 notices are included as `Source-sans-LICENSE.md` and `Source-serif-LICENSE.md`. Files are unmodified. `sources.json` records the original blob identifiers, download locations, file sizes and SHA-256 values.
