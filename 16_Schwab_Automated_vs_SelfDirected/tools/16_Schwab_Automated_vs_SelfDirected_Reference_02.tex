\vspace{7pt}{\noindent\small\color{Muted}仅供模拟使用·投资账户：自动管理还是自行管理·16-02\par}\vspace{10pt}
\subsection*{开户及入金}
自动项目最低5,000美元。登录账户，在转账与支付页面选已有账户，或用路径及账号增加外部银行账户，可以一次或定期入金。


可以开普通应税个人、联名、共有、托管及可撤销生前信托账户，也可以按资格使用IRA等账户类型。证券入金可能被出售并投入项目组合。


现有账户转入时，在在线问卷后选择加入现有账户，检查披露并完成登记。资产通常在三至五日内清算并投资。受益人按账户号码单独登记，不自动从其他账户带入。


\subsection*{修改配置}
希望改变配置时，重新检查并填写投资者档案问卷。系统按更新档案提供配置。组合按风险档案管理，不因客户逐笔交易指令改变。


\subsection*{提款及结算}
可随时登录申请转款至其他本公司账户或外部机构。请求额不超过现有现金时可以立即可用；超过时，需要出售ETF并等待结算，处理及结算通常四至六个营业日。


提款后按目标再平衡；已开通税损收割的账户若余额低于门槛，该功能可能失去资格。账户关闭等交易可能需要最多五个营业日处理。
