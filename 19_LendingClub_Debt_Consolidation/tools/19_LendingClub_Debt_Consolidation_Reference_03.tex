\subsection*{A：合并为个人贷款}
\textbf{开始时的债务处理：} 到手贷款款项结清两笔现有购买余额


\textbf{新贷款合同本金：} 15,262美元


\textbf{放款手续费：} 贷款本金的6\%，本报价列示约916美元，放款时扣除


\textbf{到手金额：} 报价列示约14,346美元，本次用于结清原债务


\textbf{利率：} 固定名义年利率13.99\%；包含手续费的披露APR为18.40\%


\textbf{合同付款安排：} 36个月，每月约522美元；末期按实际余额结算


\textbf{提前清偿：} 可以提前或额外还款，无提前清偿罚金；放款手续费已在开始时扣除


\textbf{账户管理：} 清偿后按一笔新贷款账单付款，原卡停止新增购买


\subsection*{B：保留两笔信用卡欠款}
\textbf{开始时的债务处理：} 保留原有两笔余额及账户合同


\textbf{新贷款合同本金：} 无新贷款，本次余额合计14,346美元


\textbf{放款手续费：} 无本次新贷款放款手续费


\textbf{到手金额：} 不发生新放款


\textbf{利率：} 当前两笔18.74\%／24.74\%，随优惠利率变化


\textbf{合同付款安排：} 各自每月按账单最低付款规则支付，可自行加付


\textbf{提前清偿：} 可以随时全部或部分还款，无本次贷款放款费


\textbf{账户管理：} 继续处理两张卡各自的账单和到期日，停止新增购买


\textbf{B的每张卡最低付款按以下规则计算：}账单新余额的1\%，加该期利息及适用费用，金额向上取整到整数美元；与25美元比较，取较高者。若余额不足25美元，支付全部余额。两张卡分别计算，不是合计只付25美元。


你没有逾期、超额度或本任务中的年费、加急服务费；按时付款，不办理余额转移或取现。两项均可办理自动付款，资金安排相同。选择A后，原信用卡仍可保留，但按本次计划不再增加消费余额。


\subsection*{办理确认事项}
A的手续费在放款时发生，到手款少于新贷款合同本金。每月正常还款会同时偿还本金和利息。额外付款减少之后的未偿本金和利息，新贷款原先扣除的手续费不因此变成未发生费用。


B只要满足每张卡的账单最低付款，可以自主提高还款金额；利息按合同的每日余额方法计入账单。最低付款金额随账单变化，原卡合同没有给现有余额设定固定36个月清偿日期。


本次选择的是债务合同及付款安排，不是再申请其他优惠卡。现有余额之外没有需要加入本任务的其他债务；两项都以偿还现有欠款为目标。
