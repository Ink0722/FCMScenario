# 研究数据导出与质量标记

入口：控制台 → 参与记录 → **导出研究数据 ZIP**。沿用当前列表的条件、状态、批次、配置与编号/测试码筛选范围，导出全部匹配页。也可由受管理授权保护的 `GET /api/v1/admin/research/export` 调用。

ZIP 包含 UTF-8 BOM CSV，时间统一为北京时间、带 `+08:00`。文本中的换行/引号由 CSV 标准转义，可能成为表格公式的文本前置单引号。数值 0、false 与缺失值保持区分。

| 文件 | 一行代表 | 主要内容 |
| --- | --- | --- |
| participants.csv | 一次参与安排 | 条件、批次、状态、Profile 答案及题目版本；无登录码 |
| tasks.csv | 一项个人任务 | case、顺序、模型、固定目标、选项顺序、目标规则、尝试次数 |
| attempts.csv | 一次实际尝试 | 初始/最终选择和置信度、变化量、轮数、完成候选标记、停止原因、质量标记 |
| turns.csv | 一轮对话 | 用户/正式回复文本、策略、错误、引用问题、已结算和预占费用 |
| model_calls.csv | 一次已登记模型请求 | 阶段、供应商请求/响应编号、Token、原生摘要、耗时、费用与请求/响应工件引用 |
| tool_calls.csv | 一次工具执行 | 名称、实际参数、结果、错误及时间 |
| configs.json | 一份冻结配置 | 场景、Profile 题目、Prompt、完整工具参数、策略目录和安全模型元信息 |
| manifest.json | 本次导出 | Schema 版本、范围、各类记录数量及解释 |

所有表即使为空也保留完整列名。`participant_id → task_id → attempt_id → turn_id → call_id` 用于关联。没有开始的任务保留在 tasks.csv，不虚构 attempt。放弃、取消、中断和重做不覆盖旧记录，也不自动去重。

`analysis_candidate=true` 仅表示该尝试完成了流程、保存初始/最终判断、达到最低完整回复轮数，不代表科学有效性审核通过。分析前需结合 `runtime_mode`、`collection_scope`、`target_rule` 和 `quality_flags` 筛选。质量标记包括确定性运行、开发目标规则、中断轮次和未核实引用。当前真实 Advisor 仍为本地材料联调，不能将这些标记自动解释为正式研究发布。

Neutral 的 `target_option_id` 是后台比较目标，`target_used=false`，没有发送给模型；Goal 才实际使用目标。选择变化与置信度变化直接按保存值计算，未填答案为空，不补 0。

费用以当前独立账本为准，人工核对后重新导出会反映新结算；未确认预占与已结算分开。不将“尚无用量”解释为免费。Worker 在费用登记后、轮次检查点前中断的请求也会纳入回放和导出。验证沙盒不产生参与安排，因此不混入参与者研究数据；其费用仍可在设置页查询。

导出不包含测试码、API Key、访问 Token 或加密连接工件。CSV 的 request_ref / response_ref 指向服务器私有工件库，ZIP 不打包原始供应商请求/响应；完整复现还需保留相应数据库、工件及密钥备份。configs.json 只带安全模型元信息和公开实验配置，不导出连接密钥。

## 分析口径

派生指标应单独记录定义和版本，不覆盖原始选择与置信度。早期方案提出的候选有符号分数为 `D(A)=-C`、`D(B)=+C`；若使用目标方向的前后差值，目标 B 取 `Dpost-Dpre`，目标 A 取反。此口径需由研究者确认，不作为服务端自动生成或已预注册的指标。

A/B 必须使用稳定选项身份。客观正确性需关联审核后的答案版本；自由选择顺序、多次尝试、失败和未完成的排除规则须在分析方案中另行规定，不从导出中的完成标记自动推断。
