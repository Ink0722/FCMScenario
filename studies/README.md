# 实验配置

这里定义实验任务集合与共用资源，不存真实参与者数据。

- `local-development.yaml`：当前本地验证使用的任务定义、案例语言、共享提示、Profile 文件及对话策略。
- `fixtures/local-codes.yaml`：仅供本地 Mock 的公开开发编码与任务 ID 列表。

一个 Case 是内容；一个 Task 引用 Case 并拥有独立 ID／编号；Session 是某位参与者开始任务后的作答会话。同一 Case 可以对应多个 Task，例如带／不带中测的本地检查任务。

增加任务时修改 `tasks`，使用新的稳定 `id` 和 `number`，引用已登记且具有所需语言的 `case_id`。需要本地编码访问时，再把任务 ID 加入开发夹具。无需修改 React 页面或 Mock 的任务常量。

编译器检查任务 ID、编号、案例和语言、编码引用及策略时间点，不会根据编号推断隐藏条件。没有审定英文案例时，不会静默退回中文。本地默认案例语言仍为 `zh-CN`，公共 UI 仍为英文，这一点明确写在配置中。

真实测试码生成、参与者绑定、动态完成状态、随机条件和隐藏目标留给后端。不要把正式凭证放入这个会被本地前端读取的开发夹具。
